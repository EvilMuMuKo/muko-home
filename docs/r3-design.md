# MuKo Home R3 / 13.0.0

此稿在 R2 / `53a386ec` 上实施用户确认的入户短墙比例、封闭储物岛台与两人日常餐位、内开门、厨房玻璃收口、悬空电视侧柜、斜向阅读座椅和双卧飘窗利用。实拍照片用于空间关系校正，不复制进公开仓库，不作为照片测距。

## 本轮布局

- 入户右侧建筑错台从 x=7.95 改为 x=7.10m；仅此处外轮廓与玄关/客厅共享地面边界同步更新。这个数值来自用户同意的比例试排，仍待实测。柱体及承重墙保持 R2 的位置与尺寸。
- 入户、影音室、卫浴、主卧门均内开，保持原完整门叶：1100 / 860 / 800 / 880mm。不得把缩窄门叶当作保留门洞的同义词。
- 入户左岛台保留 500×1600×950mm 及两把460mm正常餐凳，成为两人日常餐位。为避开1100mm完整门叶，台中心从 x=5.15 调至4.95，保持与柱体同宽；不再宣称中心线相同。下方为200mm深封闭浅柜，操作面朝入户通路，餐位侧保留300mm悬挑膝部空间。它没有开放展示层；保留膝部空间是就餐条件。200mm浅柜只能放小物，不能按深柜申报容量。
- 旧V11长度候选中的955mm净距已撤为历史数据；本稿厨房前缘至台端的纵向预算875mm，不直接等同于实际绕角通路净宽。
- 两凳中心 x=4.40，沿长边间距700mm，后退400mm；没有缩小餐凳或人体。退凳后600mm人体外廓与后墙水吧端部名义距离约100mm，不把这里说成背后通路。双人离席需从北侧绕行，实体舒适度仍待试坐。入口门扫掠与封闭柜把手的最小全局X余量约11mm，软件无穿插不代表现场容差足够，应以门组、把手和实际完成面放样复核。
- 玄关由1410mm整合柜缩为560mm单人换鞋位，座面440mm，鞋与少量次净衣/随身物由下格、洞洞板和上柜承担。批量衣物回主卧衣柜。原完整次净衣立柜不再存在。
- 移动电视旁原落地高柜改为底标高1400mm、深350mm的悬空柜，背面贴后墙内完成面。折叠桌椅保留实际体积和原取出路径，作为悬空柜前下方可搬离家具（折桌在柜前，折椅位于柜下）；下方没有新增固定柜体。它们停放时仍占地，不能称为始终空无一物。
- 影音室床品柜沿墙长度从1900mm减为1650mm，让人能绕过内开门末端；650mm饮料冰箱格保持原位置。
- 阅读椅转为斜向135°，唱片柜仍靠窗下墙，不占厨房出口。全屋保持移动电视、双模块沙发、无固定茶几、主卧床原朝向及床对面一字双工位。

## 厨房玻璃与真实入口

先前仅把三轨移至柜外，虽然避免穿柜，三扇原地叠放仍使入口剩余约630mm（计浅柜门/把手的保守投影）。此候选900mm目标 FAIL，未采用。

最终三扇侧玻璃全开后向北停靠在冰箱柜外侧：轨道延长一扇宽度，门叶最内面离冰箱侧板约3mm；取消妨碍滑行的起端通高立柱，终端与台上玻璃共用角柱。104mm顶轨移至柜外，避免北延轨切进通顶冰箱柜。真实柜门/把手占位与开门叠放共同扣除后，入口连续净段约1.157m，达到概念900mm目标。对应最终数值见几何测试注释。

这仍是机制概念：外停靠导轨、止摆、固定、角部收口及烟密封件未选型；不能据此宣称已实现燃气封闭或油烟验收。厨房玻璃、柜门与冰箱门全部同时开启的人体组合也不由静态无穿插证明。

## 飘窗与立体利用

双卧保持原外凸台体、750mm概念投影、2100mm窗宽、600mm台高与窗玻璃。新增可取下薄垫、托盘、侧向三层小书架及少量书，侧架落在原台体上，不虚构可掏空的结构储物，也不把飘窗计入步行地面。600mm高台是高位停留辅助，不包装成450mm正常座椅。窗扇、遮光帘、承载与防坠仍需现场核实。

## 交互与技术

触屏左半屏任意落点出现移动摇杆，右半屏任意落点出现转头摇杆；角色锁定于触点开始的半屏，跨线不切换。支持双指同时行走/转向。松手、取消、丢失捕获、失焦、旋转/resize均清零输入。按钮不启动摇杆。两只摇杆在空闲时都隐藏，桌面保留键鼠操作。

继续锁定 WebGPU / Three.js TypeScript / WASM，保留WebGL2回退、固定DPR和移动端按需渲染。本轮没有开启手机全屏AO或Bloom。新增细节采用已有材质族并参与静态分房合批。离线日/夜间接光按最终布局重生成，不继承旧柜体暗影。
