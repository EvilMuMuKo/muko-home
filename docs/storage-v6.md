# V6 上部收纳与材质改造

基于 `2bd8356` 执行，网址与 GitHub Pages 发布方式保持不变。原始 V5 数据保存在 `src/model.js`，V6 由 `src/storage-design.ts` 生成覆盖层；可追踪每个柜体的尺寸、用途、底标高、门型与容量估算。

## 空间调整

共新增或重组 24 组上部柜体，覆盖全部 8 个房间。下方已有家具的墙面也纳入设计。封闭内空估算约 4.6 m³、开放展示约 1.1 m³；这是本次 24 组柜体总容量，包含替换原柜体，**不是净增容量**。计算扣除 18 mm 板厚、分隔、层板与门板，未扣实际五金、管线及设备通风要求。完整逐项尺寸及计算见 [storage-v6.json](storage-v6.json)。

柜体由板件、背板、层板、分隔、门缝和微倒角组成。柜门具有独立铰链，厨房、工作区与高位低频柜采用上翻门；镜柜为双扇侧开。玻璃柜和开放格内有书籍、杯具等实际几何。柜底灯与展示灯按新柜体位置调整，当前房间优先获得实际光源槽位。

打开控制面板中的「收纳」，可以逐房进入审核视角、查看用途及容量，并统一展开/收起柜门。其他室内视角可查看衣柜顶部、床侧和家政柜。

## 材质与清晰度

- 自托管 Poly Haven CC0 白橡木、木地板、粗亚麻三组颜色/法线/粗糙度贴图，共 9 张 WebP、746,590 字节。颜色 1024 px，法线/粗糙度 512 px；纹理共享，运行时不请求第三方站点。
- UV 按米制尺寸映射，木纹与织物纹理不会随不同柜体尺寸被整面拉伸；各向异性过滤最高 8。亚麻颜色转中性灰后参与原奶油/鼠尾草配色，保留织纹。
- 漆面、墙面、金属保留细微粗糙度变化，柜门增加微倒角，让边缘高光有真实宽度。玻璃和镜面使用环境反射，镜面不是实时平面反射。
- 桌面使用 4× MSAA，取消原 SMAA 模糊，减弱泛光与过重的环境遮蔽；静止后恢复更高像素密度。手机交互 DPR 上限 1，静止按设备档位恢复，同时受总像素预算约束。
- 保留房间合批和按需绘制，活动门与静态柜壳分别处理；物理模块继续按需加载。没有引入高成本实时光追或大型外部引擎。

纹理来源、许可与可重建资产脚本见 [credits](../licenses/polyhaven-textures.md) 和 `scripts/prepare-materials.py`。

## 验证

本地 Chromium / SwiftShader 下 11 项 Playwright 测试通过。新增检查覆盖 8 房间及柜体 ID、原始数据不变性、静态包围盒重叠、实际门轴、开启过程不越过 2.7 m 吊顶、厨房门避让油烟机、9 张纹理加载成功及工作区上翻动作。逐房日间截图均无浏览器脚本异常，另做 844×390、DPR 2 移动视口验证。没有手机真机帧率或温控测试数据。

这些是概念模型校核，不能替代现场尺寸、设备散热要求、柜门五金选型、墙体锚固及承重深化。高位柜用途以轻型低频物品为主。
