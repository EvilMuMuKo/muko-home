# V8 温暖的私人沙龙

在 V7 `0bf6c0c` 基础上，从统一色调推进到家具轮廓与建筑构图。全屋以纸白、陶土、暖石和深木为基调，通过连续框景、低重心家具、柔软曲面形成关联：水吧开放而适合停留，客厅轻松围坐，影音室安静而有包裹感。原网址和主体户型延续。

## 设计参考与取舍

研究的重点是成熟案例中贯穿建筑与家具的做法，不把单个家具或流行墙色当作完整方案：

- [Audo House](https://audocph.com/pages/audo-house)：餐饮、居住与陈列共用温暖、克制的材质语言，家具形成可停留的组合。
- [Azabu Residence / Karimoku Case](https://www.karimoku-case.com/case_studies/azabu-residence/) 与 [Kinuta Terrace](https://www.karimoku-case.com/case_studies/kinuta-project/)：用木质界面、低矮家具、留白与光线建立整体秩序。
- [Ett Hem / Studioilse](https://www.studioilse.com/project/ett-hem/)：把生活、交谈、阅读融入同一个舒适空间，避免陈列厅式的冷淡感。

这些案例与 Claude 偏暖、有人文感的审美相协调。当前模型采用原创程序家具，不是品牌授权复刻。影音室软包、顶面为视觉与空间概念，声学性能需要另行测量与深化。

## 净空与实现

- 24 组上部柜体及估算内空不减少。卡座低于 0.9 m 窗台；水吧框景位于现有柜墙边界，避开入口。
- 柜门按 0%、25%、50%、75%、100% 的开合状态检查新增建筑体；弧顶范围据此退让，低点约 2.49 m，顶点与 2.7 m 原顶面保留间隔。
- 客厅茶几前方调整原演示路线，保留原 0.45 m 人物半径。检查实际家具包围盒；影音室保留转换、离床、储物凳离开的三条路径，新增台口不阻挡这些路线。模型检查不能代替现场复测和五金详图。
- 椭圆台、弯木椅、卡座、弧背沙发、边几、茶几和纸灯均为实际曲面几何。共享现有木材与亚麻 PBR；新暖石及细竖纹使用本地程序纹理，不新增外部纹理请求。
- 固定建筑构件按房间及材质合批；柜门、可退让椅、沙发床保留运动节点。桌面继续使用原后期效果，手机保留灯光与像素预算、按需渲染，没有为这些变化增加每帧模拟任务。
- 版本 8.0.0 通过 V8 覆盖层生成；V5 原始数据、V6 收纳及 V7 色彩层可分别检查。调试 API `getSpatialDesign()` 提供净空边界，`setCompositionStudy(true)` 可用统一灰材检查形体。

## 验证与预览

构建执行 WASM 生成、TypeScript 检查及静态发布文件同步。18 项自动化测试覆盖新建筑与柜门、家具尺寸、通行路线，以及既有渲染回退、材质、模拟和家具交互。桌面与手机横屏逐一检查五个生活场景，并补充三处侧视和灰材检查；记录见 [验证数据](salon-v8-validation.json)。

本地浏览器使用 Chromium / SwiftShader。这里的绘制统计用于回归比较，不代表 iPhone 或 Android 真机帧率；实际手机流畅度仍需真机验证。
