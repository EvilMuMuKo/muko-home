2. 阅读[有效决定与覆盖](有效决定与覆盖.md)，按“最新明确决定优先”的顺序解释冲突，并查看实现状态。

4. 阅读[V10 空间方案复核](../life-v10.md)及[测量表](../life-v10-measurements.csv)，区分模型值与现场测量。

## 决策和验收规则

后续设计不得把旧实现当作用户需求；较新的、明确的决定可覆盖原始文档中的具体家具或布局提案，但不得抹去尚未解决的核心生活目标。需求表用 `PASS` 表示所列模型或软件范围已验证；`FAIL` 表示当前模型与该项明确要求相冲突；`BLOCKED` 表示关键现场、产品或真实使用证据缺失；`NOT RUN` 表示对应检查尚未执行。一个房间可同时有模型 `PASS` 与真实使用 `BLOCKED`。

这两份新增文档只同步设计决定与证据路径，不包含私人照片或原始交接图片。不得将私人照片、未经许可的现场影像或其他私密交接材料复制到公开仓库。
