# V11 实景空间关系修订

本版基于78a5fb1，依据用户对实景空间关系的确认。照片没有上传，也未作为照搬旧装修的样板。所有米制数值仍是统一虚拟模型参数，不能施工放线。

## 已实施的空间关系

- 柱顶视图的上边与主卧承重墙上边按完成面齐平。墙中心z4.4、厚180mm、柱深500mm的当前假设下，柱中心z4.56。没有改变柱的尺寸或外框。
- 入口岛台1600×500×950mm，两把650mm座高的高坐凳同侧朝水吧，桌下320mm膝腿留空。旧小门、抽拉台面、导轨、机构仓和热点撤除。旧接口`setHatchOpen`返回不可用，不生成物件。
- 1600/1800/2000mm柜长对应厨房下沿完成面到柜尖的模拟净距955/755/555mm。本版选择满足900mm预算的1600mm，现场净距确认后可改参数。
- 厨房不向水吧侧延伸，只调整靠走廊短端。比较x4.2/4.5/4.8三档，并将外置冰箱、柜体和取物站位一起计算，选择x4.2。相对旧虚拟边界增加700mm。实际次卧门左框尚未配准，不能声称已贴齐现场门框。
- 冰箱与柜套在厨房外，操作面朝走廊；关闭状态过道预算约1735mm，计入当前取物站位后另一侧约755mm。后者低于900mm舒适目标，是概念中的侧身通行余量，不能当作两人宽松通过的验收。
- 补入水槽窗。原水槽上吊柜移至端墙，窗面保持留空；备餐柜和家电随端墙移动。
- 主卧门恢复靠入户端的关系，柜体加长，保留床朝向及床对面一字双工位。没有在主卧承重墙另开门。
- 卫浴右侧台盆、左侧马桶、后部淋浴；浴室外框深度暂用2000mm，减少过道占位，外轮廓未扩大。镜柜、侧灯、洁具和碰撞同步移动，排水与隔墙性质仍待核。
- 两间外凸飘窗暂用2100mm宽、750mm外凸、600mm台高。它们是可替换占位，不是照片量出的尺寸，也不扩大可步行地面。
- 移动电视、双模块沙发、无固定茶几、影音客房、阳台家务及整体风格保留。客厅折叠餐桌为备用。

## 软件与资料

统一模型由最终设计层生成，网格、可动件、碰撞、灯光及诊断共同读取。保留WebGPU、Three.js TypeScript、WASM、WebGL2回退及现有移动端固定分辨率、30Hz节奏；不启用移动端实时全屋烘焙。

日夜7房间共14份间接光离线重算。全屋漫步、浏览器截图、模型快照与验证结果放在[配套目录](space-v11/)。原始最高设计纲领保持原文；新增决定已进入覆盖索引。

## 边界

照片确定关系，不提供完整实测几何。真实柱宽、窗台、门洞、排水、烟道、燃气、结构墙和设备型号仍需确认。模型可运行、模拟几何可用、真实居住舒适和施工适配分别判断。真实手机验收若无设备证据为NOT RUN。
