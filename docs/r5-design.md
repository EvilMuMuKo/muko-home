# MuKo Home R5 · 已确认平面落实到模型

R5 / 15.0.0 将 A8 影音室、A9 客厅与 A10 电源点位合成同一个构建模型。沿用 WebGPU、Three.js TypeScript、WASM 和 WebGL2 回退；依赖版本不变。建筑外框、柱墙、门洞及内开门保留 R3/R4。

## 本轮实际变化

- 客厅采用 85 英寸移动电视，机身 1895×1087mm、中心高1300mm，参考底座1100×660mm；双单人模块保持单个1275×1050mm。斜向观影和活动后停统一更新渲染、碰撞与PS5/手柄配件；沙发模块转换保持左右身份，避免互相交换穿行。A9图面+205°转换为当前模型顺时针155°，二者表达同一实际朝向。
- 活动状态电视移至(10.20,8.83)m，沙发退至上侧；备用用餐保留正常餐高桌椅。取消无效的旧侧向电视状态，原接口映射为完整客厅模式。
- 影音室原大沙发床与床品柜保留；新增并排单人伊思帕沙发床，闭合1050×800mm、展开总长1920mm、内长1820mm；没有为通行缩短床体。长直桌1960×600mm、台高740mm，覆盖部分飘窗上方，四条专用腿避开床尾，左右各25mm预算。飘窗台体不掏空，覆盖区不计作步行地面。
- 新增显示器、音箱及单人椅。真实尺寸概念主机放桌后矮柜顶并转向，避免占用桌面排插；显示器有独立底座，不穿桌板。
- 影音室85英寸移动电视远位z2.84m、近位z2.44m，底座1086×849mm。近位仅在两床收起时可用；小床展开会先停靠椅子，原大床、小床和近位电视有组合保护。
- 回音壁随影音电视托架移动，低音炮退出新增小床占位，壁挂音箱与主机保持净距。旧固定电视立面边框及中右媒体柜段退出，桌后小矮柜保留；两台电视的供电模块和短设备线随架，演示中不生成横跨地面的永久拖线。

## 电源与弱电

[全屋电源图](r5/plans/02_全屋插座平面.svg)及[可编辑点位表](r5/plans/插座点位表.csv)保留全部48组点位（包含条件候选、PDU、弱电与固定接线，不能当成48组已定墙插）。数据源是 `src/electrical-layout.json`，随统一模型发布。

31组拟布置墙/柜电源、1组家具PDU采用轻量几何，按房间分别合批，关闭其他房间时不留下漂浮插座。H03顶部PoE、B06固定接线保留数据，不画成空中的墙插。柜内安装面与柜前可达面分开，柜内插座不贴在封闭柜门外侧；服务格、插头弯线与检修仍需柜体深化。14组条件项（湿区、空调、地插及其他未定设备）不渲染为已经安装。

L01服务客厅斜向与后停；C01服务影音室远近位；工位C03沿窗洞实墙引至C04桌面PDU，不穿过桌后取物间隙。插头等级、专用回路、线径、接地、防溅、电气分区、保护装置及负载由现场电气设计确认。模型中的孔槽是视觉示意，不作为采购规格或暗盒开槽依据。

## 查看与交互

保持入户默认漫步、按需浮动双摇杆和原有控制面板。在影音室靠近小床或电视可切换对应动作；房间面板内也有两个相关按钮。两床与近位电视不允许组合穿插，界面会提示先恢复哪个状态。

内部诊断继续兼容 `window.homePresentation`，新增 `getR5Revision()`、`getElectricalPlan()`、`getStudyState()`、`setStudyBedOpen()`、`setCinemaTVNear()`、`setGuestBedOpen()`。实际运行状态和碰撞读取同一可见网格；R5图纸位于 `docs/r5/plans/`，公开仓库不包含私人照片或原始标注。

## 验证边界

构建、实际网格尺寸、屏幕朝向、床/桌/椅101状态、插座分区、交互保护和原有运行回归分别记录于[验证记录](r5/validation.json)。软件检查不代替施工、五金承载、真实观影、现场居住或手机真机性能验收。手机仍采用固定像素预算与30Hz策略，不增加实时灯光、全屏AO/Bloom或反射。
