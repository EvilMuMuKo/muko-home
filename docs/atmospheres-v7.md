# V7 墙色、材质与生活场景

基于 V6 `801fc1f`，执行已确认的 Claude / Anthropic 气质方案，保持原网址、户型与 24 组上部收纳。`src/model.js` 和 V6 收纳层继续保留，V7 在 `src/atmosphere-design.ts` 叠加，版本为 7.0.0。

## 三个重点空间

| 空间           | 改造内容                                                                                                                     | 使用方式                                                                                                                                |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 早 C 晚 A 水吧 | 窗墙柔陶土色，燕麦柜门、烟熏木内格、奶油釉面砖、原创装饰画、杯具与托盘                                                       | 「早咖啡」提供日光与操作照明；「晚饮」提高杯酒展示和桌面重点光，降低操作灯                                                              |
| 客厅           | 燕麦墙面、暖灰褐电视背景、同色上柜，木材/亚麻/苔绿/陶土织物，坐垫缝线、扶手盖毯、少量游戏陈列                                | 「客厅 · 游戏与追剧」联动电视示意画面、阅读灯及低亮度背光；保留 PS5 位置与开放安装方式                                                  |
| 秘密影音室     | 烟熏炭棕墙面与柜门、炭灰屏幕背景、深色顶面与织物；名义 83 英寸屏幕、三块织物墙板、音箱构造、低绒地毯；同色门框与双面配色门扇 | 「私人影院」关闭门、遮光帘、展示照明和柜门，收起沙发床；「影音室 · 客住」保留遮光并展开沙发床、开启阅读照明。动作面板可独立开关影音室门 |

全屋衔接区域采用暖纸白，原家具平面位置保持不变。两块屏幕分别按实际朝向设置正面图像坐标；影音室屏幕增至约 1.84 × 1.035 m，顶标高 1.705 m，与上柜底标高 1.83 m 保留间隔。影院中央原展示格加可开启柜门，物品和储物内空保留；总容量估算不变，五金净空仍待深化。

## 材质与实现

- 墙体两面按实际所属房间分别赋予顶点颜色，采用共享哑光墙材；影音室颜色不会染到共墙另一侧的厨房或走廊。墙体继续可合批，保留门窗洞口。
- 各房间的木材、柜漆和织物共享原 PBR 贴图，仅使用色调和粗糙度变体。门板与层板按构件方向调整木纹；原柜架增加微倒角。
- 砖缝、釉面变化和原创图形采用小型本地程序纹理，没有增加外部图片请求。装饰网格按房间/材质合并；屏幕、门、柜门与遮光帘保留可控状态。
- 屏幕使用独立归一化 UV，显示原创静态图形，用于空间效果示意；没有内置视频服务。影院音箱与织物墙板为概念构造，不声称已完成声学测量、隔声施工或设备认证。
- 场景支持房间级灯光强度与灯具色温覆盖，实际光源数保持桌面 12、手机 4–6。电影模式中 `storage-guest-task`、`guest-wall-cove` 等灯具关闭。
- 五个主题视角优先显示当前空间及必要的相邻区域，水吧保留餐厨/走廊、客厅保留生活阳台。用户仍可「显示全屋」；普通审核视角保留全屋显示。
- 保留 WebGL / 可选 WebGPU、WASM 几何、按需绘制、手机像素预算和按需加载物理模块。可选布料模拟沿用影音室深色织物材质。

## 依据与验证

设计参考来自 [Anthropic 公开品牌调色板](https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md)、[Benjamin Moore 2026](https://www.benjaminmoore.com/en-us/paint-colors/color-of-the-year-2026)、[Sherwin-Williams 2026](https://www.sherwin-williams.com/en-us/color/color-of-the-year/2026) 及 [Farrow & Ball 整体同色处理](https://www.farrow-ball.com/colour-drenching)。这是对色彩与空间气质的转译，非品牌授权室内方案。

新增测试验证共墙双面颜色独立、源模型不变性、储物内空不变、屏幕与上柜净空，以及主题按钮联动灯光、遮光帘、门、柜门和客床。既有回退、物理、布料、水量守恒与家具交互测试继续运行。

本地完整 14 项 Playwright 测试通过，最终配色和入口按钮另作针对性复测。桌面与移动横屏分别检查五个场景，10 个组合均无脚本错误，9 张 PBR 贴图加载成功；截图位于本目录，[记录](atmospheres-v7-validation.json)包含灯光预算和显示状态。所有帧数/绘制调用统计均来自云端 Chromium / SwiftShader，不能视为 Android 或 iPhone 真机 FPS、温控或电量测试。
