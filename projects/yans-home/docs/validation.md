# 初稿验证范围

验证平台：Linux、Node.js 24、Chromium / SwiftShader。桌面 1280 × 800；触摸视口 844 × 390，另外检查 DPR 2 的手机画面。软件渲染测试用于功能与视觉取证，不是物理手机性能测试。

## 验证内容

- TypeScript 检查、WASM 编译和生产构建。
- 确认的房间用途、单电脑机位、咖啡柜岛、中央沙发、卧室床柜与电梯厅右墙公路车。
- 拓展并入、原次卧门封闭、新门开闭后的碰撞变化。
- 门默认开启时，以直径 **520mm** 的圆形身体、80mm 网格，从电梯厅搜索至 **12 个空间** 的落脚区域。此项是几何路径搜索；不宣称真人实测或全程连续键盘漫游。
- 浏览器真实按住前进键、接近实体墙停止、松键后停止；不是仅通过 API 传送作证明。
- CDP 双指触摸：左右原地出现、移动 / 转头同时输入、单独抬起一指后另一指保留、换位置重现、取消与失焦归零，UI 点击不生成摇杆。视角操作期间画布尺寸固定。
- PBR 的 12 张材质图全部加载，WASM 有实际变换记录，固定网格合批与静止时按需暂停。
- 分别模拟 WebGPU 不可用和 WASM 请求失败，确认 WebGL2 / JavaScript 回退不阻断浏览。
- 空间切换、照明、全屋概览及 PNG 导出。
- 对根目录静态产物用 `/yans-home/` 路径进行浏览器访问，检查相对资源链接、全部纹理及页面错误。

## 性能与工程边界

手机档位：65万 / 100万像素预算，DPR 上限 1.25 / 1.5，3 / 4 个灯槽，1 个局部阴影灯，512 级局部阴影，按需渲染，30Hz 调度上限；全屏后处理与动态镜面关闭。静态源网格 533 个合成 85 批（减少 448 个），活动门保持独立。WebGPU 硬件路径和物理手机的持续帧率、发热、内存、后台恢复仍需真实设备复核。

几何尺寸、真实窗景、结构拆改、设备选型、通风、排水与电梯厅现场条件未获实测，本初稿不作为施工图或现场合规结论。镜面采用环境材质，没有实时捕获；窗外是示意景观。原户型照片不进入公开仓库。
