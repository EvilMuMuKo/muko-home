# 确认需求与初稿计划

## 结论

独立建立 YAN’s Home，不把上一户住宅的功能清单搬入新户型。以用户照片的空间关系、红色标注及随后确认作为依据，先交付可漫游、可开门、可切换照明的完整初稿，通过独立 PR 审查；合并后沿用现有 GitHub Pages 公开验收。

## 执行顺序

1. 整理统一米制户型数据：外轮廓、原门封闭、新门、并入拓展区，以及独立电梯厅。
2. 建立家具层级与留白：通顶柜、桌面上柜、咖啡柜岛、中央沙发、卧室床柜、单机位桌、壁挂公路车。
3. 添加细节和材质：真实门洞与活动门扇、柜门、织物床品、木纹、窗帘、设备与生活物件；光照随空间和设备预算分配。
4. 复核软件几何通行与操作，保存逐房截图；记录不确定尺寸，不把估算写成实测。
5. 通过 muko-home 独立 PR 提交源代码、发布产物与验证记录；合并后子路径公开验收。

## 初稿假设与待复尺事项

照片底边读得 `2950 + 5000 + 3300 + 600`，与总标 `11250` 有差异。本稿按前三级构成 11250mm，右侧 600mm 拓展另计，包络 11850mm 处理。层高暂按 2800mm，门洞约 2220mm。照片未给足的墙厚、门偏置、柜深及电梯厅具体尺寸采用可调概念值，电梯厅当前约 2300 × 2400mm。

电梯厅柜深 360mm，自行车、车把和柜门另计突出并纳入碰撞包络；柜体不是一整面实心柜。玄关柜缩浅以留出转身通道，主卫采用移门并调整门偏置。连通测试使用直径 520mm 的圆形身体，只证明软件模型内的几何路线，不等同于现场人体活动或消防验收。拆改、拓展的具体结构条件仍待现场核对。
